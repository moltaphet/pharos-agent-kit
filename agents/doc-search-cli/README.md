# 4. Doc-Search CLI

> Ask the Pharos docs in plain English. Get an answer with its sources, or an honest “I don’t know”.

**Arena task:** Developer Docs MCP · Easy · [brief](https://pharos-agent-arena.vercel.app/tasks/doc-search-cli)<br>
**Try it:** https://pharos-agent-kit.vercel.app/#/doc-search-cli/try  ·  **Story, decisions and how to verify:** https://pharos-agent-kit.vercel.app/#/doc-search-cli

## What it does

The Developer Docs MCP server lets an agent search and question the official Pharos documentation. This tool wraps it in a command: ask a question in plain English and get a concise answer with the doc pages it came from.

## What is real

Concise sourced answers, and a refusal (not an invented answer) for questions the docs cannot answer.

## Requirements and how each is met

| # | The Arena requires | How it is met |
|---|---|---|
| 1 | Accepts a natural-language question as input, e.g. `pharos-docs "how do I deploy a contract?"`. | Takes a plain-English question, on the command line or in the box above. |
| 2 | Returns a concise answer plus links or references to the source doc sections. | Returns a concise answer plus the doc pages it came from. |
| 3 | Handles "no good answer found" gracefully instead of inventing one. | Says “no good answer” when the answer admits it, or when the question’s key words appear in none of the pages the docs search returns, and shows nearby pages labelled as not an answer. |
| 4 | README with install and usage instructions and 3 example queries with outputs. | README has install and usage steps and three real example queries with output. |

## Run it

From the repository root (Node.js 20 or newer):

```bash
node agents/doc-search-cli/pharos-docs.js "how do I deploy a contract?"
node agents/doc-search-cli/pharos-docs.js --json "What are the chain ID and RPC URL for Pharos mainnet?"
node agents/doc-search-cli/pharos-docs.js "airspeed of an unladen swallow"; echo $?
```

## Verify it yourself

- **Open the cited page.** Every answer lists the doc pages it came from. Open one and check that it says what the answer says.
- **Ask the docs server directly.** The same question through this repository’s MCP client, without the filtering. You will see the raw answer that our decision logic judged.
- **Try to trick it.** Ask something the docs cannot answer, like the example chip about the swallow. It should refuse, and the log’s Decision entry shows why.
