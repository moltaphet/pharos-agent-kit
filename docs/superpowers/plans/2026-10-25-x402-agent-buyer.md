# x402 Agent Buyer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Complete Arena task 21 with a usable x402 buyer that evaluates prices, enforces per-call and total budgets, safely retries one authorization, logs settled payments, and demonstrates completion and budget-stop outcomes.

**Architecture:** Add a small Node ESM buyer engine layered on the existing dependency-free x402 protocol client. Keep policy decisions (value, cap, budget) in the buyer, and keep signing in the existing `createPayment` helper. Add a CLI plan format, deterministic no-network demo, browser task content, generated submission materials, and fake-fetch regression tests.

**Tech Stack:** Node.js 20+, existing ESM modules, `node:test`, no new dependency, Pharos Atlantic x402 v2 exact scheme.

## Global Constraints

- Never store or print private keys or authorize a real payment in tests/demo fixtures.
- Only accept `eip155:688689`, exact scheme, valid addresses, valid uint256 amounts, and a consistent payment asset/domain per job.
- Never retry a payment with a new authorization after an uncertain result; retries must reuse the exact signed payload.
- Count spend only after a successful settlement receipt; reserve unresolved spend and stop the job.
- Label mock results as simulated and never present mock hashes as explorer transactions.

## File structure

- `lib/x402-buyer.js`: validate plans, read 402 requirements, decide purchase, enforce budgets, retry the identical authorization, and return JSON-safe decisions/ledger.
- `agents/x402-agent-buyer/pharos-buy.js`: CLI wrapper using the existing environment/file key loader.
- `scripts/x402-buyer-demo.mjs`: offline deterministic fixture for successful two-endpoint and budget-stop jobs.
- `reports/x402-buyer-demo.json`: generated fixture output, clearly marked simulated.
- `public/js/tasks/x402-agent-buyer.js`: task narrative, requirements evidence, demo scenarios and run commands.
- `public/js/tasks/index.js`, `public/js/consts.js`, `scripts/task-map.mjs`: register task 21 and its files/tests.
- `test/x402-buyer.test.js`: fake-fetch and injected signer regressions; no sockets, keys or chain calls.
- `package.json`: add `pharos-x402-buy` executable.
- `README.md`, generated task and submission files: update the project count and task list.
